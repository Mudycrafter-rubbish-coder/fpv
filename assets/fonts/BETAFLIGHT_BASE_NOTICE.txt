betaflight_base.mcm
===================

Source:
https://github.com/betaflight/betaflight-configurator/blob/master/resources/osd/1/betaflight.mcm

This file is the Betaflight Configurator default MAX7456 font.  It is used
here as a base so that ASCII characters, digits, and OSD symbols remain
available when Chinese glyphs are added.
