## 关键尺寸速查

坐标系：**原点 = 机架中心，单位 mm，X = 左右，Y = 前后（+Y 朝机头），Z = 向上**

| 项目 | 数值 |
|---|---|
| 轴距（对角电机中心） | **135 mm** |
| 相邻电机中心距 | 95.46 mm |
| 电机孔位 | 9×9 方形，4×M2 → Ø2.2 |
| 飞控孔位 | 25.5×25.5，**旋转 45°** → (±18.03, 0) / (0, ±18.03)，Ø2.2 |
| 中心板 | 八边形，对边 44 mm |
| 板厚 | 底板 **3.5**，上层板 **3.0** |
| 上下板净空 | **22 mm** |
| 桨盘余量 | 外沿距电机中心 ≥40.10 mm（桨半径 38.1，余量 2 mm） |
| 相机到上层板余量 | 2.5 mm |
| 打印件重量（PETG） | 底板 26.1 g / 上层板 8.6 g / 托架 2.4 g |

## 结论速查

| 问题 | 答案 |
|---|---|
| 用哪个电机？ | **1106 4200KV**（3 寸必须 4000~5000KV；6000KV 是给 2~2.5 寸的） |
| 用哪个桨？ | Gemfan **3020-3**，**1.5mm 中心孔**，T-mount |
| 用哪种电池？ | 3S 650mAh **≥45C**，XT30（45C 450mAh 只有 20A，不够） |
| 推重比多少？ | 现役 1104 约 3.7 → 换 1106 后约 **6.5** |
| 飞控电流能力？ | **每路持续 20A**（AM32 4-in-1），瓶颈不在电调而在电机 |
| 电机螺丝多长？ | **最长 M2×6**（进电机 2.5mm 上限，再长顶线圈） |
| GPS 波特率？ | **115200、10Hz**，不用改 |
| 录音模块怎么触发？ | `AVI`/`JPG` 两个脚**对地短接**，用 2N7002 + PINIO 控制 |
| 图传有安装孔吗？ | **没有**，裸板，靠扎带 |

## 下一步

1. **确认两件事**：遥控器（2.4G ELRS）和烙铁是否已有 —— 决定采购清单规模
2. 按 [docs/05-采购与预算.md](docs/05-采购与预算.md) 的第一批（¥1115）下单
3. Fusion 里继续：拆组件 → 加命名参数 → 插相机托架 → 排电容和走线空间
4. 打印前把 `work/make_frame_v3.py` 里的尺寸再核一遍（改完重跑脚本会自动校验桨盘余量）

## 工作约定

- **Fusion 是设计的唯一事实来源**，改模型要通过 `fusion_mcp.md` 里规定的 MCP 工具真正落到模型上
- 图纸的生成脚本在 `work/`，**改尺寸改脚本重跑**，不要手改 DXF
- 每次生成后跑一次 `check_frame.py`，它会检查结构完整性和轮廓闭合性
