## 关键尺寸速查

坐标系：**原点 = 机架中心，单位 mm，X = 左右，Y = 前后（+Y 朝机头），Z = 向上**

| 项目 | 数值 |
|---|---|
| 轴距（对角电机中心） | **135 mm** |
| 相邻电机中心距 | 95.46 mm |
| 电机孔位 | 9×9 方形，4×M2 → Ø2.2 |
| 飞控孔位 | 25.5×25.5，**旋转 45°** → (±18.03, 0) / (0, ±18.03)，Ø2.2 |
| 中心板 | 八边形，对边 44 mm |
| 板厚 | 底板 **3.5**，上层板 **3.0** |
| 上下板净空 | **22 mm**（= 支撑柱长度） |
| 桨盘余量 | 外沿距电机中心 ≥40.10 mm（桨半径 38.1，余量 2 mm） |
| 相机到上层板余量 | 2.5 mm |
| 打印件重量（PETG） | 底板 26.1 g / 上层板 8.6 g / 托架 2.4 g |
| 推荐打印材料 | **PLA**，底板 4.0 mm 机臂；5–6 层蒙皮、5 圈壁、60–80% gyroid，机臂根部 100% |
| 一阶机臂模态 | PLA 4.0 mm ≈ **151 Hz**（含 8.5 g 端质量）；PLA 3.5 mm ≈ 125 Hz |
| stack 孔拉脱 | 上层板前侧孔最弱：Ø5 垫片 100 N 时约 19 MPa，1000 g 等效约 35 MPa；**必须加 Ø5–6 垫片** |
| 最危险冲击位置 | **底板臂根/菱形尖角**，不是 stack 螺丝；50 N 电机载荷时臂根名义 ~43 MPa，尖角需 R2–3 倒圆 |

## 结论速查

| 问题 | 答案 |
|---|---|
| 用哪个电机？ | **1106 4200KV**（3 寸必须 4000~5000KV；6000KV 是给 2~2.5 寸的） |
| 用哪个桨？ | 主力 **Gemfan 3020-3，1.5mm 孔**；长续航再配一套 **3016-3**（同样 1.5mm 孔），两种不能混装 |
| 用哪种电池？ | 基准 3S 650mAh ≥45C；长续航 3S 850mAh 70C（注意 XT30 只到 ~30A） |
| 推重比多少？ | **≈5.5**（3020 + 650mAh，起飞 ≈183g）；3016 + 850mAh 掉到 ≈3.8 |
| M2 螺丝买什么？ | **M2×6 ×28**（16 电机 + 8 板柱 + 4 飞控下）、**M2×4 ×4**（飞控上）；套装各 10 颗 → 补买 ×6 共 20 颗 |
| 支撑柱多长？ | **M2 母母 22mm ×4**（不是 25mm） |
| 飞控怎么固定？ | 4 颗 5mm 尼龙母母柱垫高，下面 M2×6、上面 M2×4 |
| 电机螺丝多长？ | **只能用 M2×6**（M2×4 会滑牙，M2×7 顶线圈烧电调） |
| 电池引出线多粗？ | **18AWG**（20AWG 在 30A 上掉 0.3~0.5V） |
| GPS 波特率？ | **115200、10Hz**，不用改 |
| 录音模块怎么触发？ | `AVI`/`JPG` 两个脚**对地短接**，用 2N7002 + PINIO 控制 |
| 图传有安装孔吗？ | **没有**，裸板，靠扎带；天线要配 RP-SMA 弯头 |

## 下一步

1. **先改上/下板的薄弱处**：上层板前侧 stack 孔加大垫片/局部凸台，4 个长槽倒圆；底板菱形四角 R2–3、臂根加三角筋
2. 打印底板 / 上层板 / 托架（PLA、平躺、5–6 层蒙皮、5 圈壁、60–80% gyroid；机臂根部 100%）
3. 打印前把 `work/make_frame_v3.py` 里的尺寸再核一遍，改完重跑会自己校验桨盘余量
4. 装配顺序照 [z-stack 动画](docs/img/z-stack.gif) 走：底板 → 柱 → 飞控 → 上层板 → 相机 → 电池
5. 先做桨动平衡、挂重/落摔测试，再目视飞调 PID；换桨或换电池后重跑一次失控返航测试

## 工作约定

- **Fusion 是设计的唯一事实来源**，改模型要通过 `fusion_mcp.md` 里规定的 MCP 工具真正落到模型上
- 图纸的生成脚本在 `work/`，**改尺寸改脚本重跑**，不要手改 DXF
- 每次生成后跑一次 `check_frame.py`，它会检查结构完整性和轮廓闭合性
- 文档里的图全部由 `work/make_doc_assets.py` 生成（尺寸取自本文档和 `make_frame_v3.py`），
  **要改图就改脚本重跑**，别手改 `docs/img/` 里的文件
