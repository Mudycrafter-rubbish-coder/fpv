# Outputs

This folder contains files produced by the project.

| Folder | Contents |
|---|---|
| [`cad/`](cad/) | Current printable STL files |
| [`osd_font/`](osd_font/) | Chinese OSD character set and `.mcm` files |
| [`osd_logo/`](osd_logo/) | 288 x 72 boot logo BMP files |
| [`previous-versions/`](previous-versions/) | Older CAD models and simulation results |

The current CAD files are listed in [`cad/README.md`](cad/README.md).

Files under `previous-versions` are kept for reference only. They were produced before the current V5 frame changes and should not be used for a new build without checking the dimensions against the current model.
