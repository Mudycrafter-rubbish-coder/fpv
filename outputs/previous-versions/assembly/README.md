# 整机装配模态（PLA 全件）

对象：`drone.stl`，6 个独立壳体（底板 + 上层板 + 4 根 Ø3×25 柱），115.4×115.4×29 mm，PLA 约 34 g。

分析类型：**自由-自由、无阻尼线性模态**；不是飞行实测，也不是瞬态落摔。

## 文件

| 文件 | 内容 |
|---|---|
| `assembly_mode1_3d.gif` | 第 1 阶 187.6 Hz，旋转 + 呼吸变形 3D 动画 |
| `assembly_mode1_3d_preview.png` | 第 1 阶静态预览 |
| `assembly_mode2_3d.gif` | 第 2 阶 230.2 Hz，旋转 + 呼吸变形 3D 动画 |
| `assembly_mode2_3d_preview.png` | 第 2 阶静态预览 |
| `mode_frequencies.csv` | 8 阶频率、方向、1P/3P 交点、悬停放大倍数 |
| `modal_summary.json` | 网格收敛、质量、假设、结论、局限 |

## 关键结果

- 网格：0.7/1.6 mm，**86,053 节点 / 384,776 四面体**。
- 粗网格 1.0/2.2 mm 的 f1 = 198.7 Hz；细化到 0.8/1.8 mm 后 186.1 Hz；0.7/1.6 mm 后 **187.6 Hz**（与 0.8/1.8 差 0.8%，可认为收敛）。
- 前 6 阶是刚体模态；第 1 阶弹性模态 **187.6 Hz**，第 2 阶 **230.2 Hz**，第 7/8 阶 **557/561 Hz**。
- **重点**：187.6 Hz 对应 1P 约 **11.3k RPM**；230.2 Hz 对应 1P 约 **13.8k RPM**；557/561 Hz 对应 3P 约 **11.1/11.2k RPM**。这些都在 12–15k 悬停带附近，和之前“只算机臂”的结论不同。

## 假设

- 全 PLA（E=3.3 GPa，ν=0.35，ρ=1240）。
- 柱顶加 1 mm Ø6 夹紧环，代表螺丝/垫片把上层板压住；真实夹紧方式会影响频率。
- 板/柱界面粘接；不模拟螺纹、预紧、摩擦、接触。
- 4 个电机 8.5 g、电池 60 g、上板电子 15 g 集中质量。
- 动画是归一化振型，显示变形 4 mm；不是实际振幅。

## 结论

整机装配后出现了机臂单件模型没有的**整机/stack 模态**，而且前两阶正好落在悬停 1P 附近。这不是“一定会炸”，但必须用实际悬停 RPM + 黑匣子 FFT 确认；如果柱是黄铜而不是 PLA，频率会上移，下一版要按黄铜柱重跑。
