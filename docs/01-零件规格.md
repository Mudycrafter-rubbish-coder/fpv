## 电池 — 3S 650mAh（或 450mAh）

| 项目 | 数值 |
|---|---|
| 规格 | 3S（11.1V），XT30 + JST-XH 平衡头 |
| 容量 | 650mAh 为主，450mAh 为轻量选项 |
| 放电 | **≥45C**：650×45 = 29A；450×45 = 20A ✗ 不够 |
| 重量 | 650mAh 约 60 g，450mAh 约 45 g |

**判断标准**：满油四颗电机峰值 30~40A。**算电流用 C × 容量**，而且廉价电池的 C 值普遍虚标，按标称的 60~70% 打折算。

## 录像模块 — OV2640 + DVR（拆机，3 g）

| 项目 | 数值 |
|---|---|
| 焊盘 | `+` `-` `AVI` `JPG`（另有 `UART`） |
| 功能 | **AVI = 录像触发，JPG = 拍照触发** |
| 触发方式 | **对地短接**（低电平有效，松手触发） |
| **视频输出** | **没有** ✗ 纯录像机，不能当 FPV 摄像头 |
| 供电 | 实测 5V 能用 |

**历史坑**：丝印是 `AVI` 不是 `AV1` —— 一字之差，害我们绕了两轮。另外曾反接电源（限流 100mA）把它烧死一颗。
