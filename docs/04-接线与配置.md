## 飞控引脚分配

GHF435AIO V2 的可用资源：

| 资源 | 状态 | 用途 |
|---|---|---|
| UART1 | 板载 ELRS | 官方接线图标注；以 Betaflight `resource` 实读为准 |
| UART2 | `TX2/RX2/SBUS` 焊盘 | 可接外置接收机或 GPS |
| UART3 | 空闲 | 保留；第一版不再接录像模块 UART |
| UART5 | 专用于 KEPLER V 辅助控制模块 | TX/RX → MSP |
| LED（WS2812） | 空闲 | 挂灯带，或改 PINIO |
| 蜂鸣器 5V | 空闲 | **建议保留**（户外找机） |
| 电流/电压传感 | 已接电调 | 固定 |

**注意**：AT32F435CG 是 48 脚封装，GPIO 总共三十几个，陀螺/OSD/气压计/黑匣子/ELRS/USB/四路电机已经吃掉大半。**能自由支配的就是手册引出来的那几个焊盘**，不存在"板上一堆闲置 GPIO"。

**找空闲引脚的方法**：Betaflight CLI 里敲 `resource` 看现状，`resource show all`（固件支持的话）看每个引脚支持的全部功能。

**KEPLER V 辅助控制模块接法**：

| 飞控焊盘 | 辅助板 J1 | 说明 |
|---|---|---|
| UART5 TX | J1-3 `FC_UART5_TX` | 飞控发送，辅助板接收 |
| UART5 RX | J1-4 `FC_UART5_RX` | 辅助板发送，飞控接收 |
| 5V | J1-1 `FC_5V` | 只给辅助板逻辑，不给舵机 |
| GND | J1-2 `GND` | 必须共地 |

UART5 在 Betaflight 中设置为 **MSP**，建议 `115200`。辅助板通过 MSP 轮询 RC 通道、ARM 状态、飞行模式、电压和可用链路信息。

辅助板另有一个板载 USB-C 和 CH340N。插入电脑后，板上的 74HC4053 会把辅助 MCU 的 UART 从飞控 UART5 自动切到 USB 串口；拔掉后自动回到飞控 MSP。这个口只用于在线配置、自定义宏和日志，不替代 SWIO 烧录。宏先存 CH32V003 内部 Flash，写入时先缓存到 RAM，再分页提交。

## 飞控怎么固定（五金）

![飞控固定方式](img/fc-mount.png)

飞控装在底板中央，45° 摆放，孔位 (±18.03, 0) / (0, ±18.03)：

- 底板下面 4 颗 **M2×6** 向上拧进 **5mm 尼龙母母柱**（垫高是为了避开板底的元件和焊点）
- 飞控板上面 4 颗 **M2×4** 穿过板上孔位压住（咬尼龙柱 2.4mm）

垫高 5mm 之后，底板那个可选的 1.5mm 元件避让凹槽（`POCKET_OPT_1.5DEEP`）**就不用切了**。

## 录像模块触发（改由 KEPLER V 辅助板控制）

录像模块的 `AVI`、`JPG` 仍然是对地短接有效，但现在直接接到 KEPLER V 的 J5：

| 录像模块 | 辅助板 J5 | 说明 |
|---|---|---|
| `AVI` | J5-1 `DVR_AVI_N` | MCU 输出低脉冲触发录像 |
| `JPG` | J5-2 `DVR_JPG_N` | MCU 输出低脉冲触发拍照 |
| `GND` | J5-3 `GND` | 信号地 |

录像模块仍由飞控 5 V 供电。PC1/PC5 是 CH32V003 的 5 V 容忍脚，配置为开漏输出；板端各有 10 kΩ 上拉到 `+5V_AUX`。MCU 复位或断线时输出自动释放，避免误触发。Betaflight 不再为 AVI/JPG 配置两个 PINIO。

## 各部件接线

| 部件 | 接到 | 说明 |
|---|---|---|
| 电机 ×4 | AIO 电机焊盘 | 顺序按 Betaflight 的 resource 映射 |
| 图传 | **VBAT 直供**（7–24V） | 不占 5V；记得接天线，不接会烧 |
| 摄像头 | 5V + GND + 视频入 | 也可从图传的 5V 输出取电 |
| GPS | UART1 的 TX/RX + 5V + GND | 3.3V 或 5V 都行；**115200，不要改 9600** |
| GPS 罗盘（QMC5883L） | I2C（可选） | 一般不用，机尾离电机仅约 30 mm |
| 录像模块 | 5V + GND 来自飞控；`AVI`/`JPG` 接 KEPLER V J5 | 不再使用飞控 PINIO |
| KEPLER V 辅助板 | UART5 + 5V + GND；舵机信号与供电分路 | 舵机电源从独立 BEC 供给 |
| 蜂鸣器 | 蜂鸣器焊盘 | **该焊盘可能是 5V 甚至 VBAT 开关**，绝不能当逻辑脚接输入设备 |

辅助板目标尺寸为 **20 × 20 mm、4 层**；如果走线和焊盘确实装不下才放宽，硬上限 **30 × 30 mm**。板端接口最终做成大焊盘，不装 2.54 mm 排针。若 USB-C 在 20 mm 版上太占空间或难手焊，可改成 `USB 5V / D- / D+ / GND` 四个焊盘接 USB 线尾。

## 供电、电容与线径

| 项目 | 规格 | 说明 |
|---|---|---|
| 电池引出线 | **18AWG 硅胶线** | 满油峰值 34A，20AWG 在 30A 时掉 0.3~0.5V，太亏 |
| 电容 | **470µF 低阻，1 颗**（并联在电池焊盘） | 至少 220µF；3S + 600mW 图传 + AIO 没有电容会加速掉压 |
| 反接保护 | **SS14 肖特基**串在电源入口 | 正向压降 0.3V，反向截止 |
| 接头 | **XT30**（1 对足够，+1 备用） | XT30 连续约 30A —— 这就是为什么 850mAh 70C 也吃不满 59.5A |

只有在**正确极性**下测量：先万用表确认 VCC/GND 没短接。

**上电前用 1kΩ 电阻当探针**：它能拉低任何带上拉的输入脚，但伤不到任何输出脚，是判断"这个焊盘到底是什么"的通用安全手套。

## Betaflight 设置要点

| 项目 | 值 | 说明 |
|---|---|---|
| 串口 | 先读 `resource` 确认板载 ELRS 占用口 | 用外置接收机时，按实际空闲 UART 配置 Serial RX |
| 辅助控制串口 | UART5 → MSP，115200 | KEPLER V 通过 MSP 读取飞控状态 |
| GPS 协议 | UBLOX 或自动 | PU-122Q 双协议 |
| `gps_update_rate_hz` | **10** | 该模块原生 10Hz |
| 波特率 | **115200** | 模块默认值 |
| `gps_rescue_min_sats` | 8 | 起飞前等到 8 颗以上、HDOP < 2 |
| PINIO | 不使用 | 录像触发改由辅助板直接控制 |
| 双向 DShot + RPM 滤波 | 开启 | AM32 支持，免费的手感提升 |

**GPS Rescue 在推重比低时更容易被拦**：返航前飞控会先算需要多少油门，超过 `gps_rescue_throttle_max` 就直接放弃返航。

- 3020-3 + 650mAh：推重比 ≈5.5、悬停 43% → 余量充足
- 3016-3 + 850mAh：推重比 ≈3.8、悬停 51% → **换到这个组合后，飞远前必须重跑一次失控返航测试**

## 电机螺丝（最容易烧机的坑）

当前底板 4.0 mm，电机进螺丝**最多 2.5 mm** → **用 M2×6**，实际进入电机约 2.0 mm。

| 螺丝 | 露出板面 | 判定 |
|---|---|---|
| M2×4 | 0 mm | ✗ 穿不过 4 mm 底板 |
| **M2×6** | **2.0 mm** | ✓ **预留 0.5 mm，用这个** |
| M2×8 及以上 | 4.0 mm+ | ✗ **顶到线圈，直接烧电调** |

3D 打印的板厚会飘：装配时逐个量穿孔深度，接近 2.5 mm 就垫一片 Ø2.2 平垫。
上螺丝先用手拧，感觉到底就停，千万别用电动起子。

买回来混装的 M2 螺丝，**务必把 7 mm 以上的挑出来别用在电机上**。
