## 当前基线

- 飞机名：**Kepler V**。
- 机架修订：**v3**；当前分析/打印底板 **4.0 mm**、上层板 **3.0 mm**。
- 轴距：**135 mm**；动力：**1106 4200KV + Gemfan 3020-3 + 3S 650mAh**。
- 主力推重比：约 **5.5**；满油电流约 **34 A**。
- 当前相机托架打印件：`outputs/cad/v3r-camera-tray.stl`。
- 旧 `v3-camera-tray.stl` 有挡镜头前唇且坐标不直接可用，只作历史对照。

## 尚未收口

- 正式打印前按 [08](08-冲击与螺丝拉脱.md) 和 [09](09-长槽半孔拉脱.md) 加固底板臂根、菱形尖角和长槽半孔。
- 确认实际支撑柱材料；当前整机模态按 PLA 柱计算，黄铜柱需要重跑。
- 实测悬停 RPM，并用黑匣子 FFT 检查 187/230/557/561 Hz。
- 实配是 10 mm 电池扎带，Fusion 暂按 6 mm 建模；装配前复核扎带与 22 mm 支撑柱/螺丝头的间隙。
- 上层板的 4 个飞控孔目前没有用途，保留或删除要在最终版 CAD 中明确。

## 命名约定

- 整机名称统一写 **Kepler V**。
- CAD 文件名保留现有 `v3` / `v3r` 前缀，避免破坏脚本和旧链接。
- `work/` 是本地生成脚本，`outputs/` 是结果，`docs/` 是说明。
- 项目总览在根目录 [README](../README.md)，视觉索引在 [docs/img](img/README.md) 和 [outputs](../outputs/README.md)。
