# 07 · 振动、材料与 PLA 打印方案

> 分析对象：3 寸 X 机架的一根机臂，45 × 14 mm，末端 8.5 g（1106 电机 + 3020-3 桨 + 螺丝）。
> 分析类型：**无阻尼线性模态 + 单自由度受迫响应筛选**；不是整机模态，也不是飞行实测。
> 结论先行：**不用买碳纤维。PLA 4.0 mm 机臂 + 合理填充/垫片/动平衡，足够你这台 3 寸练手机。**

![材料与厚度对一阶模态的影响](../outputs/vibration/f1_materials.png)

## 1. 这次算了什么

| 项目 | 内容 |
|---|---|
| 几何 | 悬臂矩形板 45 × 14 × t mm，根部固定，末端 8.5 g 集中质量 |
| 材料 | PLA / PETG / ABS / ASA / PC / PA，均为**各向同性线弹性筛选值**，不是本机打印件实测 |
| 网格 | SfePy 2026.3，Q2 六面体；24 × 8 × 3 顶点，57,510 个四面体等价自由度规模 |
| 求解器 | `K φ = λ M φ`，shift-invert 求最低 5 阶；与工具箱 `solve_modal_block` 交叉验证，频率差 < 1e-10 |
| 端质量 | 用 Euler–Bernoulli 端质量特征方程修正；与 Rayleigh 有效质量法相差约 1–4% |
| 验证 | 裸臂一阶 FEM 与 Euler–Bernoulli 解析解差 1.5–2.0%；网格从 180 到 2,400 顶点，f1 只变 0.5% |
| 响应 | 单自由度放大系数；1P 竖向分量按旋转不平衡形式，3P 按恒幅竖向力形式 |

**不能从这个模型得到的结论**：整机中心板/支撑柱模态、飞控闭环耦合、真实阻尼、真实桨不平衡量、飞行中的陀螺频谱。要谈“真实共振”，必须做敲击/地面试车/黑匣子 FFT。

## 2. 材料/厚度对比

含 8.5 g 端质量的一阶垂直弯曲频率：

| 材料 | 厚度 | f1 | 相对 PLA 3.5 | 备注 |
|---|---:|---:|---:|---|
| PLA | 3.5 mm | 125 Hz | 基准 | 你现在这版 |
| **PLA** | **4.0 mm** | **151 Hz** | **+21%** | **推荐：最便宜、够硬** |
| PLA | 4.5 mm | 179 Hz | +44% | 更硬，但更脆、更重 |
| PLA | 5.0 mm | 208 Hz | +67% | 过头了，质量/脆性代价大 |
| PETG | 4.5 mm | 144 Hz | +15% | 韧、耐热，但你不喜欢味道 |
| ABS | 4.5 mm | 148 Hz | +19% | 需要封箱，翘边 |
| ASA | 4.5 mm | 144 Hz | +15% | 户外耐候 |
| PC | 4.5 mm | 152 Hz | +22% | 打印温度高 |
| PA | 3.5 mm | 90 Hz | −28% | 太软，不建议做机架 |

PLA 4.0 mm 的 151 Hz 正好落在“高于常见 PID/滤波频段（80–200 Hz 的上半段）、又低于悬停 1P（约 200–250 Hz）”的位置。它不是唯一解，但是**成本和性能最平衡的解**。

## 3. 为什么不用碳纤维

1. **碳纤维板是正交各向异性**，没有铺层方向、纤维体积分数和层间数据，按 60 GPa 各向同性算出来的“500 Hz”没有设计意义。本报告不把 CF 放进排名。
2. **更硬不等于更不抖**。机臂一阶频率提高后，1P/3P 交点会往高转速移动；如果交点靠近悬停或满油，反而更糟。可打印材料的一阶频率本来就已经在悬停 1P 之下，悬停时是“质量控制”而不是“共振放大”。
3. **真正的大头是桨的不平衡**。13.5k RPM 时，0.3 g·mm 的径向偏心就能产生约 0.6 N 的旋转力，和单颗电机悬停推力（约 0.45 N）同一量级。这个力是**水平方向**的，主要激励机架横向/偏航模态，不会靠把机臂加硬解决。
4. 碳纤维阻尼低，陀螺噪声可能更“尖”；同样的激励下，软一些的打印件反而有阻尼优势。

所以钱花在：**好桨 + 动平衡 + 垫片 +  spare 打印件**，比买一块 CF 板更有效。

## 4. 激励路径与 Campbell 图

![Campbell 图](../outputs/vibration/campbell.png)

![响应 vs 转速](../outputs/vibration/response_vs_rpm.png)

三个激励路径要分开看：

| 路径 | 方向 | 主要模态 | 交点转速 | 在飞行范围内？ |
|---|---|---|---|---|
| 1P 径向不平衡 | 水平（XY） | 机臂横向弯曲 f2 ≈ 0.93–1.23 kHz | 56–74k RPM | 不在 0–36k 内；但会激励整机横向/偏航模态 |
| 1P 竖向分量 | 垂直（Z） | 机臂一阶垂直弯曲 f1 ≈ 125–151 Hz | 7.5–9.1k RPM | 在低油门段，需要快速穿过 |
| 3P 桨叶通过 | 垂直（Z） | 同一阶垂直弯曲 | 2.5–3.0k RPM | 在很低油门段，幅值小 |

**关键结论**：悬停带（12–15k）在三条 1P 交点之上，满油带（28–32k）也远高于一阶交点；机臂一阶垂直弯曲**不在悬停或满油点共振**。危险区是 **2.5–10k RPM 的低油门段**，也就是慢速下降、悬停前的高度保持、低油门转弯。不要在那个区间长时间停留，快速穿过去。

## 5. PLA 4.0 mm 的打印参数

| 部位 | 参数 |
|---|---|
| 顶/底实心层 | **5–6 层**（0.2 mm 层高 → 每面 1.0–1.2 mm） |
| 壁/周长 | **5 圈**（0.4 mm 喷嘴） |
| 填充 | **60–80% gyroid**；机臂根部前 15–20 mm、电机座周围 **100%** |
| 省事版 | 整块底板 **80% gyroid** |
| 层高/喷嘴 | 0.2 mm / 0.4 mm；想更强用 0.16 mm |
| 温度 | PLA 210–220°C，热床 60°C，冷却 100% |
| 附着 | 5–8 mm brim；大薄板防翘 |
| 摆放 | **平躺**，机臂受力方向沿挤出线；不要立着打 |

**为什么不是只看填充率**：薄板弯曲的应力主要在上下蒙皮。5–6 层实心蒙皮 + 60–80% 芯材，弯曲刚度已经接近实心；如果你只打 20% 填充、3 层蒙皮，实测 f1 会明显低于 151 Hz。

## 6. 装配与调参

1. **桨动平衡**：磁力平衡架或 DIY；轻的一侧贴胶带，直到任意角度都不转。检查电机轴/桨夹是否弯。
2. **飞控软装**：AIO 的硅胶减震柱不要压扁；硬装会让陀螺直接吃机架振动。
3. **螺丝/垫片**：M2×6 是电机螺丝上限；stack 孔用 **Ø5–6 mm 钢垫片**（见 [08](08-冲击与螺丝拉脱.md)）。
4. **Betaflight**：如果电调支持双向 DShot，开 **RPM filter**（1106 常见 12N14P → `motor_poles=14`，以实际磁铁数为准）；不支持就先用动态陷波，别盲加固定 151 Hz 陷波。
5. **油门习惯**：悬停约 43%，在共振区之上；避免 20–30% 长时间悬停/慢降。需要下降时用短促油门脉冲或保持稍高转速。
6. **电池/线材**：扎带压紧，GPS/图传天线固定，避免甩线。

## 7. 验证计划

- **敲击测试**：手机加速度计贴在电机上，敲机臂，FFT 看一阶峰。预测 PLA 4.0 为 151 Hz；实测在 120–180 Hz 内算模型可信。低于 100 Hz 说明根部/填充太软；高于 200 Hz 说明实际比模型硬。
- **地面试车**：拆桨前先空转，装桨后短时扫油门 0→50%，看 2.5–10k 是否有明显峰值；不要长时间停在峰值转速。
- **黑匣子**：悬停 + 慢扫油门，FFT 陀螺数据；如果 151 Hz 附近有峰，再考虑固定陷波/软装，不要凭感觉加滤波。

## 8. 局限

- 只算了机臂，不是整机；中心板、支撑柱、电池/图传的整机模态可能更低。
- 材料是典型 TDS 中值，不是本机打印件实测；E ±20% 会让 f1 变 ±10%。
- 阻尼比是估计值；Q 和峰值高度不确定。
- 1P 竖向分量和 3P 幅值是假设，不是实测；真实值要用试车/黑匣子。
- 端质量是点质量，电机/桨的转动惯量和重心偏移没建模。
- 没有飞控闭环、接触、预紧、层间失效；不能替代飞行测试。
