# 03 · 机架设计

![Z 层叠剖视](img/z-stack.gif)

## 坐标系

**原点 = 机架中心，单位 mm，X = 左右，Y = 前后（+Y 朝机头），Z = 向上**

⚠️ 注意：**当前 Fusion 模型里底板占据 z = −4.0…0**（上层板 z = 22.01…25.01），
也就是 **z = 0 是底板的顶面**。所以"上层板在 Z=22"指的是距离底板顶面 22 mm。

> **2026-10 补充**：早期 DXF 底板厚 3.5 mm；当前做振动/冲击分析和准备打印的 STL 底板是 **4.0 mm**，上层板 3.0 mm。以 `outputs/cad/` 和 Fusion 里的实际模型为准。

## 螺丝长度怎么来的

规则：**长度 = 穿过的板厚 + 2.5mm 咬合**。完整分配表见 [01-零件规格](01-零件规格.md) 的"五金"一节，
孔位对应见下面的 `screw-map`。

![底板孔位与五金分配](img/screw-map.png)

关键几条：

- **电机用 M2×6**：底板 4.0 + 进电机 2.0，留出 0.5 mm 安全余量；M2×8 会穿入 4 mm，不能使用
- **支撑柱两端各 4 颗 M2×6**：下 4.0+2.0、上 3.0+3.0
- **飞控**：下面 4 颗 M2×6 拧进 5mm 尼龙母母柱，上面 4 颗 M2×4 穿过飞控板压住

## 两处关键的间隙校核

**桨盘余量**：底板与上层板的外沿距离任何电机中心都 **≥ 40.10 mm**，而桨的扫掠半径是 38.1 mm → 留 2 mm。
（脚本每次生成都会自动校验，改动外形后如果这个数掉到 38.1 以下会报警。）

**相机间隙**：相机托架斜面最高处 z=8.66，S1039 斜放上去顶部约 z=19.5，上层板底面在 22 → **余量 2.5 mm**。
⚠️ 这就是上层板**不能低于 20** 的原因。当初设成 17 时，相机是嵌进上层板里的。

## Fusion 里的装配步骤

1. 导入 DXF（单位 mm、比例 1），草图落在 XY 平面、原点对齐
2. 底板：从 Z=0 **向下**拉 4.0 mm（对应模型的 −4.0…0）
3. 上层板：草图抬到 **Z=22**，向上拉 3 mm
4. 相机托架：直接插入 `v3r-camera-tray.stl`，底面 z=0，位置已经摆好
5. 支撑柱：4 根 Ø6×22（实购 22mm），中心 (±17.5, ±17.5)

**自检**：导入后量三个数 —— 相邻电机孔中心距 **95.46**、飞控四孔 **25.5×25.5**、中心板 **44×44**（对边）。对得上说明没被缩放。

## 打印要求

**当前打印基线按 [07](07-振动与打印材料方案.md)：PLA 4.0 mm 机臂。**
PLA 脆、耐热差，但现有厚度、螺丝长度、整机模态和冲击分析都是按它校核的；如果改用 PETG，
不要只替换材料，必须按实际厚度重新核对电机螺丝进入量、支撑柱和整机模态。

**必须平躺打印。** 让机臂的抗弯落在 XY 平面内 —— 竖着打的话一撞就从层间劈开，这是打印机架最常见的死法。

**填充**：5 圈壁、5–6 层顶/底实心层、60–80% gyroid；**机臂根部和电机座周围单独拉到 100%**。

**螺丝孔**：PLA 不要自攻（拆两次就滑牙），走 Ø2.2 通孔 + M2 螺母/铜柱。沉台不要再挖了 —— 挖薄后只允许 M2×4，反而更麻烦。

**"防炸"的本质是牺牲式连接**：撞机时让电机先被撕掉，而不是把底板撕开。所以电机座边距留到 2 mm 以上（PAD_R=10 而不是 9），相机和 GPS 全部软固定。

## 生成脚本

`work/` 下的脚本，所有尺寸都在文件开头，改完重跑即可：

| 脚本 | 作用 |
|---|---|
| `make_frame_v3.py` | 底板 + 上层板 + 预览图；`FC_ROT_45` 一行切换飞控朝向 |
| `make_tray.py` | 相机托架 STL |
| `check_frame.py` | DXF 结构审计 + 轮廓闭合性校验 |
| `inspect_dxf.py` | 列出 DXF 里所有实体（核对别人的图很有用） |
| `make_doc_assets.py` | 生成文档用的示意图和 GIF（`docs/img/`） |

运行环境：项目根目录的 `.venv`（含 ezdxf / trimesh / shapely / pillow）。
