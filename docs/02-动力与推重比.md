# 02 · 动力系统与推重比

![两种桨怎么选](img/prop-compare.gif)

## 一条规律：KV 决定桨径，定子决定力气

`转速 ≈ KV × 电压`。所以桨多大、电压多高，就决定了 KV 的合理区间：

| 桨径 | 3S 上的 KV |
|---|---|
| 2 ~ 2.5" | 6000 ~ 8000 |
| **3"** | **4000 ~ 5000** |
| 3.5" | 3500 ~ 4500（通常上 4S） |
| 4" | 2500 ~ 3000（4S） |

**KV 选错了，桨就配不对**：6000KV 硬上 3 寸桨会过载过热；4200KV 硬上 2.5 寸桨则没劲。

## 方案对比（3S、同一机架）

空机（不含电池）**≈123 g**（含黄铜支撑柱和实配五金，算法见下面的重量账）。
悬停油门 ≈ √(1 / 推重比)。

| 组合 | 单颗推力 | 四颗 | 起飞重量 | 推重比 | 悬停油门 | 满油总电流 |
|---|---|---|---|---|---|---|
| 1104 4300KV + 3016-3（旧机） | ~140 g | 560 g | ~178 g | ~3.1 | ~57% | ~20 A |
| 1204 6000KV + 3016-2 | ~190 g | 760 g | ~180 g | ~4.2 | ~49% | ~38 A |
| **1106 4200KV + 3020-3（主力）** | **~250 g** | **1000 g** | **183 g** | **~5.5** | **~43%** | **~34 A** |
| 1106 4200KV + 3016-3（续航） | ~200 g | 800 g | 183 g | ~4.4 | ~48% | ~27 A |
| 1106 4200KV + 3020-3 + 850mAh | ~250 g | 1000 g | 208 g | ~4.8 | ~46% | ~34 A |

推力数字：1106 参照 EMAX 官方 4500KV 在 3S 下 280 g 的标称往下折算；其余为按定子体积与社区实测的估算，误差 ±15%。

**两种桨怎么选**：

- **3020-3**：主力。有劲、抗风、能拉高，满油 34A。
- **3016-3**：备选。电流降到 ~27A，电压掉压小、手感柔，续航大概 **+8%**（容量没变，
  省的是峰值电流和掉压，不是悬停效率的质变），抗风差一档。
- 换桨**不用重调 PID**；但悬停油门从 43% 变成 48%，**飞远前要重跑一次失控返航测试**。

## 为什么排除 1204

- **1204 的定子体积是 12×4 = 48，1106 是 11×6 = 66** —— 1204 小 37%，扭矩能力反而更弱
- 它只有 6000KV 一种规格可选，而 6000KV 属于 **2~2.5 寸**的 KV 段
- 结论：3 寸用不了，2.5 寸又不如同 KV 的 1106 → **在任何路线上都不是最优解**

## 为什么 1104 是瓶颈

- 定子 11×4，官方标 **最大电流 5.2A / 最大功率 62.4W**
- 而飞控的 AM32 电调每路有 20A —— **电调完全过剩，瓶颈在电机本身**
- 桨已经配到 3016-3（官方标注 "designed specifically for 1104 motors"），桨这条路已经走到头

## 电流与电池

满油四颗峰值：1104 约 20A / **1106 + 3020 约 34A** / 1106 + 3016 约 27A。

电池的放电能力 = **C 值 × 容量**：

| 电池 | 可用电流 | 判定 |
|---|---|---|
| 3S 450mAh 45C | 20 A | ✗ 两个方案都不够 |
| 3S 450mAh 75C | 34 A | ✓ 刚好 |
| **3S 650mAh 45C** | **29 A** | ✓ 日常够（满油会掉压） |
| 3S 650mAh 70C | 45 A 标称 → 折算 ~30 A | ✓ 更稳，首选 |
| **3S 850mAh 70C** | **59.5 A 标称 → 折算 36~42 A** | ✓ 最宽裕，但重 85 g 且 XT30 只到 ~30 A |
| 3S 850mAh 45C | 38 A | ✓ 也够 |

**两个经验**：廉价电池的 C 值按标称的 60~70% 折算；电池线上的压降也不能忽略（20AWG 在 30A 时约 0.3~0.5V，
所以引出线用 **18AWG**）。

**实飞验证**：满油拉一把，看 OSD 电压。3S 掉到 **10.5V 以上**健康，掉到 **9.9V（3.3V/节）以下**说明电池撑不住。

## 续航

- **650mAh → 850mAh**：容量 +31%，但起飞重量 +14%，抬升功率涨得更快 → 实际续航 **大概 +8~12%**，
  换来的是更肉的手感和更高的悬停油门。
- **3020 → 3016**：峰值电流 34A → 27A，掉压小、飞得稳，续航 **≈ +8%**。
- 两个一起换（850mAh + 3016）：推重比掉到 3.8，是"最肉但最久"的组合，**飞远前一定测返航**。

## 重心

不含电池的部分重心落在 **y ≈ −3.3 mm**（略偏后，因为图传和 GPS 都在尾部）。这个数还是按旧的质量模型估的，
这版把柱子和五金算重了十几克 —— 装配完拿实际称重再核一次。

→ **电池往前放 5~7 mm** 即可配平，扎带槽的范围足够，不用改任何几何。

**关于重心高度**：不要把上层板压低来降重心 —— 电池只占全机质量的三分之一，上层板降低 5 mm
重心也只降 1.6 mm，而代价是相机直接撞上层板。对四轴来说重心高度本来就影响很小。
