### 省钱的三条路

**用手机当屏幕**：EWRF ROTG01 那种 USB OTG 的 5.8G 接收棒约 ¥80，插手机上看画面，替掉眼镜。
缺点是屏幕在手上，飞行体验不如眼镜，但起步完全够。

**遥控器买二手**：ELRS 遥控器二手很常见，这东西不像电机，摔不坏。

**先目视飞**：第一批只买"能飞"的最小集，先不带图传飞。听起来像退步，其实一开始目视飞最好：
能听电机声音判断震动、能直接看姿态、调好 PID 再上图传，摔了也知道怎么摔的。

## 买东西时容易买错的五样

| 项目 | 坑 |
|---|---|
| 桨 | **3020-3 / 3016-3 都有 1.5mm 和 2mm 两种中心孔**，电机是 1.5mm 轴 |
| 电机螺丝 | 只能用 **M2×6**：M2×4 咬 0.5mm 会滑牙，M2×7 顶到线圈烧电调 |
| 支撑柱长度 | 是 **22mm**，不是 25mm（25 会把上层板顶高 3mm，图纸全对不上） |
| 电池 | 看放电倍率不看容量：45C 450mAh 只有 20A，不够；而且 XT30 连续只到 ~30A |
| B3 充电器 | 有 220V 直插版和 12V 输入版，买错还得配电源 |

## 拆机电机验货清单

1. 手拨一下，听有没有沙沙的轴承声
2. 捏住轴承位置轴向/径向晃，**有旷量直接放弃**
3. 看线材绝缘有没有破皮、焊点有没有发黑过热
4. 万用表量三相电阻，三个值应基本一致
5. 铁螺丝靠近定子，四颗吸力应相近（弱的那颗可能退过磁）
6. **四颗必须同型号同 KV**
